⚙️ Configurar Cloudflare

Para usar la IA realmente, necesitas conectarte a Cloudflare Workers AI. Es gratis para empezar. Tus datos se guardan localmente en la máquina.

  1. Entra en dash.cloudflare.com y crea una cuenta gratuita.
  2. Obtén tu Account ID en la página de inicio del panel.
  3. Crea un API Token (perfil → API Tokens → Create Token → Workers AI).
  4. Guarda ambos en el archivo credenciales.json de la carpeta de la app:
{ "accountId": "TU_ACCOUNT_ID", "apiToken": "TU_API_TOKEN" }

Reinicia la app tras guardar el archivo.
